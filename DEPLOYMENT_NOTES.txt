Vercel + GitHub Pages deployment notes

1) Upload the contents of this folder as the project root.
2) The secret page is protected.html and is opened by the bottom-right gta button.
3) The password is set in BOTH index.html and protected.html with:
   var SITE_PASSWORD = "xodevv";
4) The YouTube embed is in protected.html:
   https://www.youtube.com/embed/Asbu8Fsmiv8
5) The download file is linked in protected.html:
   downloads/wowww.zip

GitHub Pages:
- Push these files to your repo root (or docs/ folder).
- Enable Pages in repo settings.
- .nojekyll is included to avoid GitHub Pages processing issues.
- 404.html is included as a fallback page.

Vercel:
- Import the repo as a static project.
- vercel.json is included.
